## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Permettre à l'utilisateur de retrouver ses médias via une vue d'exploration de collections, avec une expérience proche d'un explorateur de fichiers classique.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 L'utilisateur voit une vue listant ses collections sous forme de dossiers avec une icône de dossier et le nom de chaque collection.
- [ ] #2 Les collections imbriquées sont représentées de manière compréhensible pour naviguer dans la hiérarchie.
- [ ] #3 Quand l'utilisateur ouvre une collection, l'app affiche les médias rangés dans cette collection.
- [ ] #4 La vue des médias d'une collection permet d'ouvrir le détail d'un média comme depuis l'inbox ou la recherche.
- [ ] #5 Les états vide, chargement et erreur sont gérés pour la liste des collections et pour le contenu d'une collection.
- [ ] #6 La fonctionnalité respecte les collections/folders déjà créés par l'utilisateur lors de l'enregistrement de médias.
<!-- AC:END -->
